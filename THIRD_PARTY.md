# Third-party sources and dependencies

Runtime dependency: `github.com/coder/websocket` v1.8.15, ISC, [LICENSE.txt](https://github.com/coder/websocket/blob/master/LICENSE.txt). The Go standard library and runtime retain their upstream licenses.

The Chrome and Firefox extensions each bundle project code, unmodified `@ghostery/adblocker` with its dependency code, and the pinned official filter source data, together with their licenses and notices; see [Filtering data and engine](#filtering-data-and-engine).

The extension pages bundle React and React DOM (MIT), Base UI and Floating UI (MIT), Motion (MIT), lucide-react (ISC), clsx, tailwind-merge and class-variance-authority, and their dependencies. Each bundled package's license file is in the extension's `licenses/` directory and listed in `licenses/packages.json`. The UI components in `extension/ui/src/components/ui` come from the [coss UI](https://coss.com/ui) registry (MIT); its license is beside them and ships as `licenses/coss-ui-MIT.txt`. The stylesheet is generated by Tailwind CSS (MIT).

Development tools (TypeScript, Oxc, esbuild, Vite, Tailwind CSS, resvg, Playwright, Next.js, Fumadocs, ws and type definitions) are locked in `pnpm-lock.yaml`; their licenses remain with their packages and they do not ship with the daemon or the extensions. The demo site in `scripts/media/fixtures` uses icons from `lucide-static` (ISC). Chrome for Testing is downloaded from Google's official distribution solely for integration tests and is not redistributed in this repository.

Benchmark-only packages are separately pinned in `benchmarks/tools/package-lock.json` and excluded from release runtime bundles. The agent-browser release binary is downloaded with a verified digest only for CI measurements. Native archives include the Go and coder/websocket license texts.

## Filtering data and engine

Both extensions bundle unmodified `@ghostery/adblocker` 2.20.3 (MPL-2.0), its dependency code under the accompanying package licenses, and the pinned official filter source data described in `third_party/filters/sources.lock.json`. In each extension directory, the Ghostery license and the license files of the bundled packages are in `licenses/`, listed in `licenses/packages.json`. `filters.bin` is compiled from the original list text, which is redistributed with its headers and notices in `filter-sources/`. No ownership of those lists is claimed.

Comparator dependencies and payloads are development and CI only and do not ship in the daemon, SDK or extensions. Vendor binaries are downloaded into a disposable CI directory after hash verification and are not redistributed.
