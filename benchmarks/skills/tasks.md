# omw skill scenarios

You have the installed oh-my-webbridge skill and its offline references. For each independent case below, give the concrete next commands or decisions and the observations that would let you finish. You may consult the installed references as needed. Answer in case order. This is a desk exercise. Do not contact the daemon or open a browser.

1. Both browsers are paired. Read the order details from the Firefox background tab the user designated by exact URL. Two eligible tabs match. The user wants their current focus preserved.
2. In Chrome a three-step batch filled a quantity, clicked Place order, then failed at step 3 while waiting for the receipt. The user wants to know whether an order exists. What do you do if the receipt remains unavailable?
3. A separate click returned `command_not_sent`. On a later click the connection was lost with `outcome_unknown`. How do you proceed in each case?
4. Read a long article in an iframe across multiple responses. The selected iframe reloads halfway through. Explain how to continue and which references and offsets to use.
5. Export a PDF of a signed-in Firefox-only page. The user requires that exact browser profile and also wants a screenshot. What can you deliver through omw?
6. A task holds tab 7 (owned result), 8 (owned draft), 9 (borrowed), and 10 (owned work in progress). Hand 7 and 9 back to the user, close 8, and continue working on 10. What if a requested release fails?
7. An archive in a newly opened task tab is missing controls. Diagnose whether blocking caused it and verify the result. The user also has a separate borrowed archive tab.
8. An agent kit script must connect Playwright at browser level to an already running, explicitly configured native endpoint. An extension connection is also present. Which interface and endpoint do you select, and how do you protect the credential?
