# Additional omw skill scenarios

Use the installed oh-my-webbridge skill and its offline references. Give the concrete next commands or decisions for each independent case. This is a desk exercise. Do not contact the daemon or open a browser.

1. A researcher supplied only the hostname of the active tab in the last focused Firefox window. Read the page in place. At the end they want the tab left open and the task session ended.
2. You have an earlier full-page snapshot, then a newer snapshot scoped to a form. Which element handle do you use for the next fill? The value contains quotes, a newline and literal shell substitution syntax. Describe how to submit the arguments and check the result.
3. Firefox has scripts disabled. The user only needs the text of a heading and the checked state of a checkbox. Keep the current settings and profile.
4. Two task sessions in the same Firefox profile use the same site. The user asks whether they can clear cookies in one session without affecting the other. What happens, and what action do you take?
