## 取用已登入的瀏覽器 [#access-to-a-signed-in-browser]

## 更適合用其他工具的情況 [#when-another-tool-fits-better]

- **Agent 只透過 MCP 呼叫工具。** Playwright MCP、Browser MCP、Chrome DevTools MCP、agent-browser、PinchTab 與 Playwriter 可作為 MCP 伺服器執行。oh-my-webbridge 沒有 MCP 伺服器；Agent 依技能説明執行 `omw call`。
- **Windows。** Kimi 瀏覽器擴充功能、Playwright MCP、Chrome DevTools MCP、agent-browser、Claude in Chrome 與 OpenCLI 桌面應用程式支援 Windows。Playwriter 支援 WSL，PinchTab 發布有限支援的 Windows 執行檔。oh-my-webbridge 在 macOS 與 Linux 上執行。
- **Microsoft Edge。** Kimi 瀏覽器擴充功能、Browser MCP 與加上 `--extension` 的 Playwright MCP 可在 Edge 中使用。oh-my-webbridge 支援 Chrome 與 Firefox。
- **從擴充功能商店安裝。** oh-my-webbridge 已在 Chrome 線上應用程式商店和 Firefox 附加元件商店上架。兩個商店都會更新瀏覽器擴充功能。daemon 需另外安裝與更新。請參閲[開始使用](./getting-started.mdx#install-the-extension)。
- **同時連接多個瀏覽器設定檔。** 一個 Browser MCP daemon 最多連接 8 個瀏覽器或 Chrome 設定檔。oh-my-webbridge 的 daemon 接受一個 Chrome 連線與一個 Firefox 連線。
- **每個任務使用獨立的 cookie。** agent-browser 的工作階段、PinchTab 的設定檔、Playwright MCP 的 `--isolated` 與 `isolatedContext`，以及 Chrome DevTools MCP 的 `isolatedContext` 會分開 cookie。oh-my-webbridge 的所有工作階段共用瀏覽器設定檔。
- **沒有桌面瀏覽器**，例如在 CI 中。agent-browser、Playwright MCP、Chrome DevTools MCP 與 PinchTab 會啓動自己的瀏覽器，需要時以無頭模式執行。oh-my-webbridge 需要一個已安裝擴充功能且正在執行的 Chrome 或 Firefox。
- **效能、記憶體與網路除錯。** Chrome DevTools MCP 記錄效能追蹤、執行 Lighthouse 並讀取堆積快照。Playwright MCP、Chrome DevTools MCP 與 agent-browser 可以模擬網路回應。
- **在已登入的分頁上使用完整的 Playwright API。** Playwriter 在你開啓其擴充功能的分頁上執行 Playwright 程式碼。
- **常用網站的現成指令。** OpenCLI 附帶轉接器，可從 100 多個網站取回結構化資料。
- **工具內含模型。** Claude in Chrome 與 Kimi 側邊欄以自己的模型執行任務。browser-use 以你設定的模型執行任務，Stagehand 則在指令碼中加入 AI 步驟（`act`、`observe`、`extract`）。oh-my-webbridge 執行你所使用的 Agent 送來的指令，本身不含模型。
